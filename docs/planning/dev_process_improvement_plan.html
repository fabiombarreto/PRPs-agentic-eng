Problemas resolvidos
01
Muita interação manual — cada etapa exige um comando e aprovação separados
→ resolvido pelo comando único de implementação + orquestrador de agentes
02
Testes manuais E2E — maior gargalo atual do processo
→ resolvido pelo container isolado + Test Runner com auto-correção
03
Regras de negócio ignoradas — não estão explícitas no prompt
→ resolvido pelo /domain/areas + decision-gate + Docs Updater pós-aprovação
04
MCP Figma com contexto excessivo — confunde o que a IA deve implementar
→ resolvido pelo agente /figma-to-spec que filtra e produz spec.md antes do PRD
05
30 permissões a cada sessão — interrupção constante no Claude Code
→ resolvido via .claude/settings.json com permissões pré-aprovadas (Fase 3)
