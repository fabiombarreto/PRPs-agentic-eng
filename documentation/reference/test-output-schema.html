Test output schema

The canonical JSON shape every test framework's output is normalized into. Produced by normalize-test-output.mjs; consumed by the B3 classifier, the B4 auto-correction loop, the B5 post-green reviewer, and the B6 report generator. One schema across pytest, Playwright, Vitest — and any framework relay integrates later.

Schema v1

{
  "run_id": "string (UUID generated per session; same id for all attempts in a run)",
  "attempt": 1,
  "tier": "unit | integration | e2e",
  "framework": "pytest | playwright | vitest",
  "outcome": "PASSED | FAILED | FAILED_AFTER_N_RETRIES | FAILED_TIME_BUDGET_EXCEEDED | SKIPPED_UPSTREAM_FAILURE",
  "duration_ms": 12345,
  "counts": {
    "passed": 142,
    "failed": 3,
    "skipped": 0,
    "total": 145
  },
  "failures": [
    {
      "suite": "AssessmentListPage",
      "test": "filters by institution",
      "file": "frontend/tests/e2e/assessment-list.spec.ts",
      "line": 42,
      "message": "expect(received).toBe(expected) - received 1, expected 2",
      "stack": "Error: ...",
      "category": "legitimate | infra | weak_test | flaky | null",
      "raw_framework_output_ref": "classname#testname"
    }
  ],
  "coverage": {
    "lines_pct": 78.4,
    "branches_pct": 65.1,
    "source": "reports/vitest-coverage/coverage-final.json"
  },
  "artifacts": {
    "junit_xml": "/absolute/path/to/reports/results.xml",
    "playwright_trace": "/absolute/path/to/reports/trace.zip",
    "coverage_raw": "/absolute/path/to/reports/coverage-final.json"
  },
  "generated_at": "2026-04-21T17:05:00+00:00"
}

Field reference

run_id
UUID. Generated once per /relay-test session by the calling command (or auto-generated by the normalizer if absent). Reused across retries so the B6 report can correlate attempts.
attempt
1-based. Initial run = 1. First retry = 2. Maximum is 1 + max_test_retries (default 1 + 3 = 4).
tier
Layer this run belongs to when layered execution is active. unit for flat runs without layers.
framework
Which tool produced the native output. Informs the B3 classifier's heuristic table (some patterns are framework-specific, e.g., psycopg.OperationalError only appears in Python-based runs).
outcome
Top-level verdict. PASSED only when counts.failed == 0 and counts.total > 0. SKIPPED_UPSTREAM_FAILURE when zero tests ran (e.g., previous layer failed and skipped this one). The two FAILED_* termination codes are set by B4 (auto-correction loop) — the normalizer emits plain FAILED when any test failed; B4 upgrades based on what ended the loop.
duration_ms
Wall-clock of this single attempt, in milliseconds. Per-run time_breakdown lives in run.json, not here.
counts
Summary. Invariant: total == passed + failed + skipped.
failures[].category
Populated by the B3 classifier after normalization; starts as null from the normalizer. Values:
  • legitimate — bug in production code.
  • infra — environmental problem (Docker, DB, service down).
  • weak_test — test itself is broken. Reserved; not emitted by B3 in MVP (B5 post-green review is the actual guard).
  • flaky — non-deterministic. Patterns: timeouts, race conditions; or same failure across attempts without code change.
failures[].raw_framework_output_ref
Pointer back into the raw JUnit XML for anyone who wants the full context. Format is framework-specific (classname#testname for pytest and Vitest; spec-file#test-title for Playwright).
coverage
Optional. Populated only when a coverage report was emitted and provided to the normalizer via --coverage. lines_pct and branches_pct may be null when the raw format isn't parsed yet (MVP — each framework's coverage schema needs a dedicated adapter).
artifacts
Absolute paths to the raw framework outputs, for audit and debugging. Always includes junit_xml; optionally playwright_trace and coverage_raw.
generated_at
ISO-8601 UTC timestamp.

What is NOT in the record

The schema is deliberately small — one record per framework run per attempt. Cross-cutting data lives elsewhere:

  • time_breakdown (infra_setup, per-attempt durations, correction time, etc.) — lives in the run-level run.json.
  • layers: section with per-layer outcome + duration + tests_run — lives in run.json.
  • secrets_redacted footer — lives in run.json.
  • files_changed_by_autocorrection — captured by B4 during the loop in run.json, not by the normalizer.
  • Per-attempt git diff — stored at attempts/<N>/diff.patch, not in record.json.
  • Redacted execution log — at attempts/<N>/stdout.log, not in record.json.

The B6 report generator reads the record plus all these siblings to assemble the final Markdown.

Observability directory layout (component C4)

<worktree>/PRPs/reports/<feature>/

Schema versioning

Schema version is implied by the presence/absence of fields — the normalizer reads each field defensively. Breaking changes require:

  1. Adding a top-level schema_version field.
  2. Dual-write compatibility for at least one relay release (both old and new field shapes emitted).
  3. A decision entry in docs/decisions.md explaining the migration.

Evolution protocol:

  • New optional fields: just add them. Existing consumers ignore unknown fields.
  • Renaming: remove + add, with both present during the transition. Document the deprecation.
  • Removing: deprecate first, announce in docs, remove in a future release.

Framework-specific mappings

pytest (JUnit XML via --junitxml)

  • <testsuite> root (single suite) or <testsuites> (multiple).
  • <testcase classname="..." name="..." file="..." line="..." time="..."> — classname is Python-path-dotted.
  • <failure message="...">...</failure> or <error> for failed tests.
  • <skipped> for skipped.
  • tier defaults to e2e for runs under backend/tests/e2e/, unit otherwise.

Playwright (reporter: [['junit', ...]])

  • <testsuites> root with one <testsuite> per spec file.
  • <testcase classname="<spec-file>" name="<test-title>" time="...">.
  • <failure> carries the assertion error (expect(received).toBe(expected) style).
  • Traces at reports/traces/ when trace: 'retain-on-failure' — passed via --trace.
  • tier defaults to e2e.

Vitest (reporters: [['junit', ...]])

  • <testsuites> root.
  • <testcase classname="<describe-block>" name="<test-name>" time="...">.
  • <failure type="..."> includes matcher diff.
  • Coverage at reports/vitest-coverage/coverage-final.json (v8 provider) passed via --coverage.
  • tier defaults to unit.
