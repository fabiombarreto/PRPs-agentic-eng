Installation

How to get relay running on your machine and enabled in Claude Code. No npm install, no build step — the plugin is markdown + JSON + a couple of Node.js scripts.

Prerequisites

Claude Code
Any recent version that supports the plugin marketplace format. Installed on the machine you run /relay-* commands from.
Node.js ≥ 18
Bundled with Claude Code, so it's already available if Claude Code runs. The relay scripts (normalize-test-output.mjs, generate-final-report.mjs) need it.
Git
For cloning the plugin repo and for the worktree management commands.
Docker (recommended, not required)
Needed for the Test Runner's isolated test environment. Without Docker, tests fall back to local execution with a warning — see graceful degradation.
GitHub CLI (gh)
Needed for the final /relay-pr step to open pull requests. Without it, the report is still generated and you open the PR by hand.
Context7 MCP (optional)
If available, the context-builder auto-generates docs/libs/ with version-specific library docs. Without it, the skill skips that phase gracefully.

Step 1 — Clone the repo

relay is distributed as a Claude Code plugin marketplace. Clone the repo anywhere on your machine:

git clone https://github.com/<your-org>/PRPs-agentic-eng.git
cd PRPs-agentic-eng

The repo contains the marketplace manifest at the root (.claude-plugin/marketplace.json) and the relay plugin at plugins/relay/.

Step 2 — Enable the marketplace in Claude Code

Open Claude Code and point it at the marketplace manifest:

  1. In Claude Code, open the plugin settings panel.
  2. Add a new marketplace; when prompted for the path, select the .claude-plugin/marketplace.json file at the repo root.
  3. Claude Code will show the relay plugin in the marketplace list — toggle it on.

After enabling, the skills, agents, and commands from plugins/relay/ become available in every Claude Code session where the marketplace is active.

Local-only install

Until the plugin is published to a public marketplace, you're running it from a local clone. Pull latest periodically to get new agents and fixes; no uninstall/reinstall needed.

Step 3 — Verify it's working

Open a Claude Code session in any project directory and type *help in the context-builder skill. If the skill responds with its command list, relay is installed correctly:

*help

→ context-builder skill loaded
  commands:
    *init      full setup
    *update    preserve + add missing
    *validate  check limits only
    *domain    rebuild docs/domain
    *libs      refetch library docs
    *gate      regenerate decision-gate
    *help      this message
    *exit      exit persona

If you get nothing, the marketplace isn't enabled — double-check Step 2.

Step 4 — Initialize a target project

Every project you want to drive with relay needs to go through the context-builder once. This produces the docs/ tree, .claude/settings.json, methodology.md, and the redaction extensions file.

Open Claude Code in the project directory and run: 

*init

Follow the First run guide for a walkthrough of what happens and what you need to review.

Updating relay

To pull in new agents, fixes, or refactors:

cd PRPs-agentic-eng
git pull

Next Claude Code session picks up the changes automatically — the marketplace reads from disk on each session start.

If the update changes the .claude/settings.json catalog (new allowed commands, new denies), re-run *update in each target project to sync the per-project settings with the new catalog. Existing human-added entries are preserved.

Uninstalling

  1. In Claude Code's plugin settings, disable the marketplace.
  2. Delete the cloned repo (rm -rf PRPs-agentic-eng).
  3. Optionally, in target projects, remove the generated artifacts (CLAUDE.md, docs/, .claude/settings.json, PRPs/). They're plain Markdown / JSON and harmless if left in place; you just stop updating them.

Common installation issues

Skill doesn't appear after enabling

Restart Claude Code. The marketplace is read at session start; a running session won't pick up a newly-enabled marketplace until reload.

${CLAUDE_PLUGIN_ROOT} doesn't resolve

This variable is set by Claude Code for plugin-internal file references (used by hooks and the skill's catalog reads). If your Claude Code version is older than the variable's introduction, upgrade. See the troubleshooting guide.

Node scripts fail with "command not found"

Ensure node is in your PATH. Claude Code bundles Node but the scripts are invoked via the Bash tool, which uses the shell's PATH. which node should print a path; if it doesn't, add Node's binary directory to PATH.
