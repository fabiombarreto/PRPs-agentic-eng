Changelog

History of every user-visible change to the documentation site. Versioning is independent of the relay plugin version (see AGENTS.md §7 for the rules). Entries follow the Keep a Changelog convention: Added / Changed / Deprecated / Removed / Fixed.

How to read

Newest at the top. An Unreleased block accumulates in-flight changes; when a release is cut, it is renamed to the new version with the release date. All dates in ISO format (YYYY-MM-DD).

0.7.2 — 2026-04-28

Patch — reorder the plan-reviewer Step 4 (auto-flip happy path) operations so the jsonl write happens BEFORE the plan-flip Edit. Surfaced during the dogfood review of implementation-authoring Phase 1: the original ordering (flip Edit first, then jsonl Write) produced a spurious "Error editing file" retry when intervening Bash calls between the rubric run and the flip invalidated the harness's Read cache. The reordered Step 4 does the autonomous Write first (no Read requirement), then a fresh Read immediately before the Edit, keeping the flip on a warm cache. Semantic invariants (re-validation, both flip and jsonl emitted before the summary) are unchanged.

Format notes

The site follows its own semver independent of the relay plugin (per AGENTS.md §7.1):

  • Patch (0.x.Y) — typo fixes, wording, broken-link repair. No structural change.
  • Minor (0.X.0) — new pages, new sections, new NAV entries, new CSS components. No breaking change to existing content.
  • Major (X.0.0) — breaking restructure: renamed folders, removed pages, overhauled theme. Migration notes accompany the entry.

Pre-1.0 cadence: minor bumps frequently, major bumps rarely, patch bumps whenever a single fix goes in alone. After 1.0 the site is considered externally stable and removal of any page triggers a major bump.
