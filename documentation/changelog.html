Added

  • plugins/relay/agents/plan-reviewer.md — new deterministic check R-COH-VALIDATE-PATTERN-UNGROUNDED, the 10th fixed R-COH-* item. Fails a validation command whose match pattern cannot match the text it targets, in either polarity: (a) a value scraped from a tool's stdout with a guessed format, when the plan neither pins a machine-readable reporter, nor quotes a verbatim output sample, nor falls back to the tool's own exit code; and (b) a case-sensitive presence grep whose pattern is not a byte-exact substring of the literal the same plan's **ACTION**: prose instructs be written. An unmatched pattern makes the gate always-pass; a mis-cased one makes it always-fail. Both shapes were confirmed in a single dogfooded plan, and both had correct exit-code semantics — so neither R-COH-VALIDATE-ALWAYS-PASS nor R-COH-VALIDATE-FORBIDDEN-GREP-SCOPE applied. The documented rubric[] arithmetic moves from 17–22/17–25 to 18–23/18–26. See docs/decisions.md 2026-08-04.
  • plugins/relay/agents/plan-writer.md, docs/context/plan-template.md — the matching authoring-time guidance: a Hard constraint 11 pointer, Step 4.4 item 11 wrong/right examples, a new anti-pattern bullet, and mandatory extension 7. Same three-site enforcement pattern the 2026-07-09 and 2026-07-23 validation-command decisions established.
  • docs/context/conventions.md — a real ## Test patterns section, replacing the stale "no test suite yet" claim that had stood since the validation suite shipped on 2026-07-12. Documents the two invocation conventions the repo's own plans kept re-deriving wrong: pass a quoted glob (a bare directory throws Cannot find module, which reads as a broken corpus rather than a bad invocation), and read the exit code rather than scraping the reporter (the default reporter emits ℹ fail 2; # fail 2 appears only under an explicit --test-reporter=tap).

0.24.0 — 2026-07-31

Shifts the rubric left. Each of plan-writer, implementer, and test-writer now runs a named pre-emission self-check covering only the defect classes that measurably reject it, placed where its first-authoring path and its prior_feedback revision path converge on the terminal write. The motivating measurement: after 0.23.1 closed the feedback pipe, 50 percent of plans and 34 percent of implementations still failed their FIRST review, and 0.23.1 cannot move those numbers by construction — prior_feedback is null on attempt 1. Format notes

The site follows its own semver independent of the relay plugin (per AGENTS.md §7.1):

  • Patch (0.x.Y) — typo fixes, wording, broken-link repair. No structural change.
  • Minor (0.X.0) — new pages, new sections, new NAV entries, new CSS components. No breaking change to existing content.
  • Major (X.0.0) — breaking restructure: renamed folders, removed pages, overhauled theme. Migration notes accompany the entry.

Pre-1.0 cadence: minor bumps frequently, major bumps rarely, patch bumps whenever a single fix goes in alone. After 1.0 the site is considered externally stable and removal of any page triggers a major bump.
